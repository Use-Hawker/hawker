Open a stall

Have an API? Sell it by the call.

Put a price on one call and agents can buy it today. You sign the listing with the wallet you want to be paid to. That wallet is the only one that can change or close it.

  • You get paidOn every call, in USDG, straight to your wallet, in the same transaction the buyer pays in. There is no balance to withdraw.
  • The fee3% of the price. The till's code caps it at 5% for good.
  • Your APIAny https endpoint that takes a JSON POST and answers within 30 seconds, up to 1 MB.
  • Failed callsA 4xx or 5xx from your API is passed on and not charged. Only a 2xx answer is paid.
  • PriceFrom 0.02 to 100 USDG a call. We pay the gas of each settlement.
  • HoldersA seller holding the $HAWKER minimum pays no fee at all, once the token is live.

Signing is free: a message, not a transaction. Your stall is paid to the wallet that signs. To change a stall, send the same slug again from the same wallet.

Check the signature

Every paid call reaches your URL as a POST with the buyer's JSON as the body, plus these headers. Refuse anything whose signature does not match or is older than five minutes: then only HAWKER can make your API do paid work.

HeaderValue
X-Hawker-Signaturesha256= + hex HMAC-SHA256 of timestamp + "." + raw body, keyed with your signing secret
X-Hawker-TimestampUnix seconds when HAWKER sent it
X-Hawker-BuyerThe wallet that is paying for this call
X-Hawker-CallThe call ref. The same ref is in the Paid event on chain.
 
import { createHmac, timingSafeEqual } from 'node:crypto';

export function fromHawker(req, rawBody, secret) {
  const ts = req.headers['x-hawker-timestamp'], sig = req.headers['x-hawker-signature'] || '';
  if (!ts || Math.abs(Date.now() / 1000 - Number(ts)) > 300) return false;
  const want = 'sha256=' + createHmac('sha256', secret).update(`${ts}.${rawBody}`).digest('hex');
  return sig.length === want.length && timingSafeEqual(Buffer.from(sig), Buffer.from(want));
}
import hmac, hashlib, time

def from_hawker(headers, raw_body: bytes, secret: str) -> bool:
    ts = headers.get("x-hawker-timestamp", "")
    sig = headers.get("x-hawker-signature", "")
    if not ts or abs(time.time() - int(ts)) > 300:
        return False
    want = "sha256=" + hmac.new(secret.encode(), f"{ts}.".encode() + raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(sig, want)
async function fromHawker(request, rawBody, secret) {
  const ts = request.headers.get('x-hawker-timestamp'), sig = request.headers.get('x-hawker-signature') || '';
  if (!ts || Math.abs(Date.now() / 1000 - Number(ts)) > 300) return false;
  const key = await crypto.subtle.importKey('raw', new TextEncoder().encode(secret), { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']);
  const mac = new Uint8Array(await crypto.subtle.sign('HMAC', key, new TextEncoder().encode(`${ts}.${rawBody}`)));
  return sig === 'sha256=' + [...mac].map((b) => b.toString(16).padStart(2, '0')).join('');
}

From the command line

The agent kit opens stalls too. The key it signs with is the wallet the stall is paid to.

hawker list weather-now https://api.example.com/weather 0.05 "Weather Now" "Current temperature and wind for a city."
hawker close weather-now https://api.example.com/weather 0.05

Questions

When exactly am I paid?

Your API answers with a 2xx, then HAWKER lands the buyer's signed payment through the till. The USDG reaches your wallet in that transaction, and only then does the answer go back to the buyer. If the payment cannot land, the buyer gets no answer.

Can someone call my API without paying?

Not through HAWKER, and not at all if you check the signature: only HAWKER has your signing secret. Your URL is never shown in the catalog.

What do I answer when the input is wrong?

A 4xx with a JSON body. HAWKER passes it to the buyer as sellerReply and charges nothing.

I lost the signing secret.

Send the listing again from the same wallet with "Give me a new signing secret" ticked. The old one stops being used at once.

Who decides what can be listed?

Anyone can list. HAWKER hides stalls that phish, lie about what they return, or break the law. Hiding stops new calls and never touches money already paid.
