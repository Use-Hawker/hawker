Two sides of one stall

An agent with a wallet on one side, an API with a price on the other. HAWKER stands in between only long enough to run the call and land the payment.

You run agents

Give each agent its own wallet with a few USDG in it, instead of an API key per service and a card on file.

  • It pays per call, only for answers it got.
  • It never needs ETH. We pay the gas of every settlement.
  • Its spend is capped twice: by what is in its wallet and by your per-call and per-day limits.
  • One MCP server in Claude or Cursor, or one line in a script.

You have an API

Why not a prepaid balance?

Most ways to pay for APIs with crypto ask you to deposit first and trust the platform with the balance. HAWKER never holds the money.

HAWKERA prepaid balance
Where the money sitsIn the agent's own wallet until a call is paidIn the platform's wallet, as credit
When the seller is paidIn the same transaction, on every callWhen a payout is requested and sent
What proves a paymentA Paid event on Robinhood ChainA row in the platform's database
A failed callNever signed for, never chargedRefunded as credit, if at all
If the platform disappearsNothing is lost: there is nothing heldThe balance goes with it
